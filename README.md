# Solveway course files

Shared files for the Solveway AI and automation apprenticeship. Clone this next to your own vault.

## How to use it

1. Clone this repository into a folder named **`Course-Files`**, sitting beside your own vault in your `Vaults` folder.
2. Before each session, open GitHub Desktop, click **Fetch**, then **Pull**, so you have the latest files.

**Do not change anything in here.** It is updated before each session, and your changes would be overwritten. If you want to build on something, copy it into your own vault first.

## What is in here

| Folder | What it holds |
|---|---|
| `Prompts` | Starter prompts to run at your own vault |
| `Vendor-Courses` | The online courses you do between sessions, with dates. Read-only: copy them into your own vault |

More is added as the programme goes on.

## Why the folder name matters

If you clone this into a folder with any other name, and that folder ends up inside your own vault, your course files will show up as changes waiting to be saved in your own repository. If that happens, clone it again into a folder called `Course-Files`.
